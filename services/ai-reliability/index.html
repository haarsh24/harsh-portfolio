Questions people ask

What is an LLM fallback cascade?
An ordered list of model providers. A request goes to the first; if it times out, is rate-limited or errors, it moves to the next, so users still get an answer.
What is a circuit breaker?
A pattern that stops sending requests to a service that keeps failing, for a short cooldown, so users do not wait on timeouts you already expect and the service has room to recover.
How do you test reliability?
By simulating failures on purpose: slow responses, random 500s, dropped connections and jitter. Hiccup is an endpoint built to do exactly that.
How long does reliability work take?
Typically 1–2 weeks, depending on how many providers and request paths are involved.
Can you add this to an app that already exists?
Yes. The cascade sits behind a single function, so it can be introduced to an existing app without rewriting the rest of it.
